One assistant on the website and on WhatsApp

The WhatsApp bot runs the same engine with the same clinic file as the website chat: the same answers, the same buttons, the same booking steps. Patients already know the clinic's number, so on WhatsApp the bot doesn't ask for it.

1
Patient messages the clinic on WhatsAppAny question, any wording. Buttons and lists appear exactly like in this preview.
2
The assistant answers from the clinic fileHours, location, services, FAQ. Standard or AI, the same as the website.
3
Appointment requests go to the clinic's emailName, phone (taken from WhatsApp), email, preferred day and time, marked "Source: WhatsApp".
What a clinic needs for WhatsApp: a Meta Business account with a verified WhatsApp Business number on the WhatsApp Cloud API, and our small server (a free Cloudflare Worker) connected to it. Meta charges for WhatsApp conversations according to its own pricing, and the AI version also uses the clinic's own AI API key.

This page is a live preview: it runs the real assistant and the real WhatsApp message format in your browser. Nothing is sent to WhatsApp.
