# Connect 4

لعبة Connect 4 كاملة تعمل في المتصفح: لاعب ضد الكمبيوتر بثلاثة مستويات صعوبة، مبنية بتقنيات الويب الأساسية فقط (HTML و CSS و JavaScript) بدون أي مكتبات خارجية وبدون خطوة بناء.

## المميزات

1. لعب ضد الكمبيوتر بثلاثة مستويات: سهل، متوسط، صعب
2. ذكاء اصطناعي بخوارزمية Minimax مع Alpha Beta Pruning
3. شبكة 7 أعمدة × 6 صفوف مع كشف تلقائي للفوز أفقياً ورأسياً وقطرياً ولحالة التعادل
4. حركة سقوط واقعية للقطع مع ارتداد، وتمييز واضح لصف الفوز بخط مضيء ونبض للقطع الأربع
5. معاينة لمكان سقوط القطعة قبل اللعب
6. اختيار من يبدأ اللعب، وزر تراجع عن آخر حركة
7. لوحة نتائج تحفظ تلقائياً في المتصفح
8. واجهة عربية وإنجليزية بضغطة زر
9. مؤثرات صوتية يمكن إيقافها
10. تصميم متجاوب يعمل على الجوال والتابلت والكمبيوتر
11. دعم كامل للوحة المفاتيح: الأرقام من 1 إلى 7 للعب، والأسهم للتنقل بين الأعمدة

## التشغيل

الطريقة الأسهل: افتح الملف `index.html` بالضغط عليه مرتين. اللعبة تعمل مباشرة في أي متصفح حديث.

أو شغلها عبر خادم محلي:

```bash
npx serve .
# أو
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المتطلبات والمكتبات

1. لتشغيل اللعبة: متصفح حديث فقط (Chrome أو Edge أو Firefox أو Safari)
2. لتشغيل الاختبارات: Node.js إصدار 16 أو أحدث
3. المكتبات المستخدمة: لا يوجد. الكود كله JavaScript خالص
4. الخط Rubik يحمل من Google Fonts، وإذا لم يتوفر اتصال تستخدم اللعبة خط النظام تلقائياً

## الاختبارات

```bash
node tests/run-tests.js
```

يشغل 29 اختباراً آلياً تغطي:

1. قواعد اللعبة: الفوز في الاتجاهات الأربعة، العمود الممتلئ، التعادل، التراجع
2. الذكاء الاصطناعي: اقتناص الفوز الفوري، صد تهديد الخصم، اكتشاف الفوز الإجباري، الالتزام بزمن التفكير
3. القوة الفعلية: مباريات كاملة تثبت أن المستوى الصعب يتفوق على المتوسط والمتوسط على السهل

## كيف يعمل الذكاء الاصطناعي

الملف `js/ai.js` يطبق Minimax بصيغة Negamax مع أربع تقنيات لتسريع البحث:

1. **Alpha Beta Pruning**: تجاهل الفروع التي لا يمكن أن تغير النتيجة
2. **ترتيب الحركات**: تجربة الأعمدة الوسطى أولاً، مما يجعل القص أسرع بكثير
3. **Iterative Deepening**: البحث بعمق 1 ثم 2 ثم 3 وهكذا داخل زمن محدد، فتكون هناك دائماً إجابة جاهزة
4. **Transposition Table**: حفظ المواقف التي سبق تحليلها باستخدام Zobrist Hashing حتى لا تحلل مرتين

دالة التقييم تفحص كل مجموعات الأربع خانات الممكنة على اللوحة (69 مجموعة) وتعطي نقاطاً للمجموعات المفتوحة حسب عدد القطع فيها، مع أفضلية للعمود الأوسط.

مستويات الصعوبة:

1. **سهل**: يبحث بعمق حركتين ويلعب حركة عشوائية في 30% من الأدوار
2. **متوسط**: يبحث بعمق 4 حركات، يصد التهديدات المباشرة ويبني هجمات بسيطة
3. **صعب**: يبحث لمدة 0.8 ثانية في كل دور ويصل عادة إلى عمق 14 حركة أو أكثر

## التعديل

1. تغيير قوة المستويات أو زمن التفكير: من `LEVELS` في `js/config.js`
2. تغيير الألوان والمقاسات: من المتغيرات في أول `css/style.css`
3. إضافة لغة: أضف كائناً جديداً في `js/i18n.js` بنفس المفاتيح
